# 阶段 P0：实现冻结与环境基线

> 完成日期：2026-09-19  
> 状态：**complete**  
> 权威顺序：以 `implementation-roadmap.md` 的 P0 卡片为准；旧计划中把依赖安装和模型下载放入 P0 的内容已经废止。

## 1. 本阶段唯一目标

把设计决策冻结为后续编码会话可直接执行的清单，并建立不依赖个人路径、密钥、设备、音色或模型缓存的环境基线。

## 2. 已确认的环境事实

| 项目 | 当前事实 | P0 结论 |
|---|---|---|
| 目标平台 | Windows 单机 | 冻结为 MVP-1 平台；不通过管理员权限解决安装或运行问题 |
| 目标语言 | Python | 冻结；运行时最低版本为 Python 3.10 |
| 当前虚拟环境 | `.venv/pyvenv.cfg` 记录 Python 3.12.10 | 目录存在，但当前解释器不可启动，不能视为可用环境 |
| 当前 Python 发现 | `py.exe` 存在，但报告没有已安装 Python；`.venv` 记录的基础解释器路径不存在 | 作为 P1 开始前的环境阻塞检查；P0 不安装、不修复、不下载 |
| API 凭证 | 根目录 `.env` 含本地 TTS 配置变量 | 真实值只允许位于环境变量或未提交的 `.env`；不得进入日志、计划、截图或 Git |
| 模型 | `models/` 为本地模型/缓存目录 | 默认忽略；P0 不下载、不验证模型 |
| 运行数据 | 统一放入用户选择的仓库外 `data_root` | 不把个人绝对路径写成通用默认值；源码仓库不得作为运行数据根目录 |

## 3. Git 与隐私基线

根目录 `.gitignore` 已排除：

- `.env` 和其他真实本地环境文件，同时允许提交 `.env.example`；
- `.venv/`、Python 缓存和测试缓存；
- `models/`；
- 旧设计中可能落在仓库内的 `logs/`、`plans/`、`memory.md` 和单文件计划/结果；
- 诊断音频和常见音频文件。

正式运行时计划、审计、索引和临时音频使用仓库外 `data_root`。`.gitignore` 是最后一道防误提交保护，不替代运行时路径校验和隐私策略。

## 5. P0 明确不做

- 不创建业务代码、测试目录或项目代码骨架；
- 不安装依赖，不运行 `pip install`，不生成最终依赖锁定文件；
- 不下载或修改 ASR、TTS、唤醒词、声纹或其他模型；
- 不接入 Tool、Agent、ASR、TTS 或界面；
- 不修复当前 Python/虚拟环境，只记录可观察事实并交给 P1 入口检查。
