## 新对话建议实施顺序（不是本轮完成项）

1. **复核候选与权限边界**：核对本机 VoiceStudio 健康状态、`e8572e8e` Profile 的身份及已认可试听文件；只读取必要非敏感信息，避免泄漏正文/凭据。
2. **设计并保存私有默认选择**：在助手私有配置里显式绑定该 Profile ID，设计安全持久化、用户归属、版本边界和无效 Profile 的 fail-closed 行为；不可仅改引擎默认声线。先记录可回滚的原设置。
3. **实现真实接缝而非偷换 fake 端口**：明确 `/generate` 请求/响应、音频字节、编码/采样率/通道、设备格式转换、队列提交点、超时、取消/停止回执、资源上限与安全日志。真实 Provider/设备接入须与任务/授权事实隔离；不可用时保留完整文字。
4. **先提供显式文字试播入口**：用户主动输入非敏感短句，按句依序合成并在选定设备实际播放；测试失败/超时/打断/设备不可用、旧回复不续播、文字保留。逐项区分「收到音频」「已提交设备」「设备完成回执」「用户实际听到」；不能用内部 PLAYED/fake ACK 代替听感。真实播放只在新对话确认合适条件后进行。
5. **让用户听感确认**：先核对音高、语速、稳定性和是否仍像已认可的候选声线；如果听感不符，暂停默认接入并回退文字，不自行重设计声线。
6. **Agent 回复出口就绪后再接入**：当前 `app/main.py` 尚无真实 Agent 回复出口，不要通过假接线宣称「助手已会说话」。接入后单独验证跨回复身份、语音与文字一致、取消/停止及安全回归，再更新 P7 T-04/T-05/T-06 验收证据。验收全部通过前继续停在 P7，不自动进入 P8。
