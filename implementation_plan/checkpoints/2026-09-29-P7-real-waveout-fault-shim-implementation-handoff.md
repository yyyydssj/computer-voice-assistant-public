- `<PROJECT_ROOT>\app\tts\playback_worker.py`

    - `UNKNOWN_AFTER_REAL_RESET`
    - `TIMEOUT_AFTER_REAL_RESET`
  - `WaveOutPlaybackBackend(fault_mode=...)` 可注入模式
  - 注入前仍然真实调用 `waveOutReset`，之后才改写 stop 分类；不替换 DLL、不终止进程，WinMM 资源被保留
  - 故障路径置位 `_output_uncertain`，`close()` 不再释放 backend，避免 WinMM 仍持有的 buffer/callback 被回收
  - 新增 `fault_mode` 注入开关与离线失败闭环测试

- `<PROJECT_ROOT>\tests\tts\test_waveout_diagnostics.py`
  - 覆盖 UNKNOWN shim，并验证真实 backend seam 调用了 `waveOutReset`。
  - 覆盖 TIMEOUT shim，并验证真实 backend seam 调用了 `waveOutReset`。
