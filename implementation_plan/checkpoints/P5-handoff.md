## 1. 本阶段唯一目标

在纯文字模式下建立最小、可停止、可验证、可审计、可恢复且默认不重复副作用的电脑任务安全闭环。所有执行必须绑定冻结计划、Manifest、目标状态和一次性授权；状态无法确认、审计追加失败或身份不一致时必须 fail-closed。

3. 执行前路径、哈希、参数、计划版本、Manifest 和目标状态复检；
4. Execution Ledger、attempt、executor instance 与 fencing token；

8. 分层重试：只读瞬态故障有限重试，Agent 必须新 request，副作用默认不重试，未知结果先扫描。
