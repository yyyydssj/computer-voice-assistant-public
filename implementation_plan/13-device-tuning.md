- 目标：调出好手感，并验证不同输入/输出设备异常时不会破坏语音会话和安全状态。
- 步骤：
  - [ ] 调唤醒灵敏度、声纹阈值、VAD 静音时长、确认超时
  - [ ] 反复试真实对话，记录误触发/漏触发/识别错误
  - [ ] 校准两阶段打断：疑似插话降音量延迟、ducking 音量比例、持续人声确认时间、前置缓冲和恢复曲线
  - [ ] 分别测试键盘、咳嗽、敲桌、风扇、音乐、扬声器回声、近讲、远讲以及不同扬声器音量；记录误降音、误停播、漏打断和用户开头丢字
  - [ ] 测试 AEC 可用、AEC 不可用以及设备延迟变化时的降级行为；不得把 AI 自己的播报提交给 Agent
  - [ ] 测试固定设备不存在、被占用、权限拒绝、运行中断开、输出设备断开和用户手动切换
  - [ ] 验证设备异常时保留文字模式、清理临时音频、失效未完成语音确认且不改变执行计划
  - [ ] 把问题记入 `../progress.md` 错误日志
- 验收：日常使用流畅；真人插话能快速收声且开头不明显丢失；回声和短暂噪声的误停播率可接受；AEC 降级行为明确；设备异常有明确提示；不会自动切换到未知设备；设备切换只在下一轮生效
