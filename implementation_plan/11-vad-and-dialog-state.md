- 目标：在 MVP-1 之后实现“说完自动停、自动走完流程、回到待机”，并为最终连续对话保留状态机边界。
- 步骤：
  - [ ] `audio/` 加 VAD：唤醒后录音，连续静音约 1 秒判当前发言结束；这一阈值结束的是一轮输入，不是整段连续会话
  - [ ] `main.py` 实现状态机（待机/监听/用户说话/转写/对话修复/思考/确认/执行/播报/被打断），asyncio 驱动
  - [ ] 清晰且稳定的 ASR final 结果只提交一次；由对话主控继续判断闲聊或电脑任务
  - [ ] ASR 没听清、低可靠性或空识别时进入“对话修复”：不显示识别文本、不提交 Agent、不产生计划/工具调用/授权；用当前 VoiceProfile 提示“没听清，请再说一遍”，随后继续监听
  - [ ] 多人重叠时不使用识别结果，提示“请一次只说一个人”，随后继续监听；不得用于电脑操作或 L2/L3 授权
  - [ ] 以 `utterance_id` 和事件身份去重；关闭、取消、设备异常或已处理轮次的迟到事件不得重新触发对话
  - [ ] 语音播报完成后一轮回待机；连续对话阶段在会话窗口内继续等待下一轮输入，超时才退出
  - [ ] MVP-1 的 TTS 播放期间暂停普通录音；实时对话阶段再允许播放期间继续监听
- 产出：VAD 与对话主控循环
- 验收：唤醒后不用按键，自然说话→自动识别→回复→按阶段策略回待机或进入下一轮连续对话
