# P0 冻结清单与实现基线

> 冻结日期：2026-09-19  
> 状态：**complete**  
> 作用：这是 P1-P11 编码会话的 P0 输入清单，不替代各共享设计文档。

## 1. MVP 范围冻结

### MVP-1 必须实现

- Windows 单机；
- 文字安全闭环优先，再接入按键触发的中文语音输入；
- 本地 ASR、DeepSeekHarness 主 Agent、结构化工具调用；
- 工作区内文件操作、系统信息只读查询、系统黑名单；
- 文件改动经过 ActionPlan、预检、L2/L3 授权、执行、验证和审计；
- TTS 输出、文字降级、执行文档、结果文档、日志和用户手册。

### MVP-1 不由以下能力阻塞

- 后台唤醒词、声纹、VAD 连续对话、实时打断、AEC；
- 音色克隆、浏览器自动化、GUI 控制；
- 永久删除、任意 PowerShell、管理员权限操作。

### 后续里程碑

- MVP-2：VAD、唤醒、连续对话、声纹误触发过滤、TTS 打断和降噪；
- MVP-3：AEC、托盘、开机启动、单实例、设备恢复、长期运行、打包和更多 Skill。

## 2. 跨模块契约冻结

### 2.1 身份与关联

必须保留并贯穿事件、日志和序列化模型：

`instance_id`、`session_id`、`utterance_id`、`request_id`、`task_id`、`plan_id`、`execution_id`、`action_id`、`attempt_id`。

执行器可额外使用 `executor_instance_id` 与 `fencing_token`，但不得替代上述身份。

### 2.2 授权与安全事实

- `plan_hash`；
- `authorization_snapshot_hash`；
- 规范化目标和目标状态快照；
- 授权动作集合、风险等级、确认窗口和过期时间；
- 计划或目标发生任何实质变化时，旧确认和旧授权立即失效。

### 2.3 状态正交

任务/授权状态与音频/Provider 状态正交。ASR、TTS、麦克风、扬声器或 Provider 故障只能改变交互通道，不得改变任务结果、计划哈希、授权状态或执行事实。

### 2.4 重试边界

- 传输层重试、Agent 请求重试和电脑副作用动作重试必须分开；
- 未提交的请求可以在有界策略内重试；
- 已开始或结果未知的副作用动作不得原地重试；
- 先扫描真实状态，不能确认时使用 `state_uncertain`。

### 2.5 崩溃与恢复

- 崩溃、强制终止或重启后不自动续跑；
- 不复用旧计划、旧授权、旧确认、旧音频或旧 Provider 请求；
- 不自动补做、不自动回滚、不把审计记录当作电脑当前真实状态；
- 用户决定继续后创建新计划或新版本，重新预检并授权。

## 4. 环境与配置基线

| 项目 | 冻结规则 |
|---|---|
| Python | 最低 3.10；不写死个人解释器路径 |
| 配置 | 通用默认值进入配置模型；个人路径和设备由用户配置 |
| 密钥 | 仅环境变量或未提交 `.env`；公开仓库只允许 `.env.example` |
| 数据根 | 用户选择的本地、非仓库、非系统目录；不得使用 UNC/网络路径或不可靠链接 |
| 模型 | 本地缓存，不提交 Git；版本与来源在首次引入它的阶段固定 |
| 日志与历史 | 纯闲聊默认不落盘；工作审计和计划按冻结的 `data_root` 结构管理 |
| 降级 | 语音组件失败时保留文字与安全闭环；降级不能扩大权限 |
