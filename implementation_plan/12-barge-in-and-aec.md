## 目标

在最终实时对话阶段实现自然的语音插话：AI 播报时继续监听，用户一开口先让 AI 快速“收声”，确认是真人持续说话后彻底停止旧回复，同时避免扬声器回声、键盘声、咳嗽或碰撞声造成误打断。

本阶段不改变 MVP-1 的“播放期间暂停普通录音”策略；两阶段打断只在实时连续对话阶段启用。

## 已确认设计：两阶段打断

```text
TTS 播放参考音频
→ AEC/回声相关性过滤
→ 降噪与 VAD 检测疑似用户插话
→ 第一阶段：快速降低 TTS 音量
→ 结合持续人声、回声相关性和人声特征二次确认
├─ 确认为用户插话：停止播放、取消合成、清空旧回复队列、进入用户发言
└─ 判定为回声或短暂噪声：平滑恢复音量、继续原播报
```

### 第一阶段：疑似插话

- 检测到疑似真人开口后，目标是在约 100 ms 内开始降低 TTS 音量。
- 初始建议降至原音量的约 20%～30%，让 AI 像真人一样先停下来听，而不是继续抢话。
- 必须保留至少约 300 ms 的麦克风前置缓冲，避免二次判断期间丢失用户开头几个字。
- 此时只改变播放音量，不立即把噪声当作一轮用户输入，也不产生 Agent 请求、电脑操作或授权。

### 第二阶段：确认真人插话

- 初始建议在检测到约 200～300 ms 的持续可信人声后确认打断。
- 判断不能只依赖单一 VAD 阈值，应综合：持续时间、人声概率、扬声器参考音频相关性、播放状态、降噪结果和设备延迟。
- 确认为真人插话后：
  - 立即停止当前 TTS 播放；
  - 取消当前 VoiceStudio 合成；
  - 清空未播放音频队列；
  - 不再提交旧回复剩余文本；
  - 已生成文字可留在界面，但旧回复不再继续播报；
  - 将前置缓冲与后续音频合并为同一 `utterance_id`，进入用户下一轮发言。
- 判定为键盘声、咳嗽、碰撞声、短暂环境声或残余回声时，平滑恢复原音量并继续当前播报，不建立用户轮次。

以上时间、音量和概率数值是阶段 13 的初始调优范围，不是不可修改的硬编码值。

## AEC、降噪与降级顺序

- 优先获取实际送往输出设备的 TTS PCM 作为 AEC 参考信号，而不是重新合成或估算参考音频。
- 对齐输入与播放参考的时间戳、采样率和设备延迟；设备切换后旧的延迟估计失效，应从下一轮重新校准。
- 处理链原则上为：AEC/回声抑制 → 降噪（NS）→ 自动增益（AGC，谨慎使用）→ VAD/插话判断。
- 实现时评估 WebRTC Audio Processing 或操作系统/音频设备提供的硬件 AEC；具体实现以真机稳定性为准。
- AEC 不可用或效果不足时，不伪装为已可靠消除回声；降级到“播放状态 + 回声相关性 + 更严格持续人声阈值 + 两阶段降音量”。
- 降级会降低打断灵敏度，但不得自动关闭实时会话，也不得把扬声器回声提交给 Agent。

## 人物模板体验

- 降音量和停播动作应像自然对话中的“收声听用户说话”，无需额外播放机械提示音。
- 用户插话后，AI 的下一次回应仍必须遵循当前人物模板和 VoiceProfile，保持连续人格。
- 如果系统不能可靠判断是否为插话，宁可恢复播报或在用户说完后按“没听清”规则修复，也不能猜测内容并驱动电脑操作。

## 安全确认例外

- 安全确认提示被打断时，本次确认提示立即失效，必须重新完整显示和播报。
- 用户插话本身不等于授权；第一阶段降音量也不进入授权识别。
- L3 仍只接受提示完整结束后、有效独立确认状态中的完整固定短语“确认执行”。

## 实施步骤

- [ ] 在播放链路输出同步的 TTS PCM 参考帧和时间戳。
- [ ] 接入并评估 AEC、NS、AGC，记录不同设备组合的可用性和延迟。
- [ ] 实现疑似插话后的快速 ducking、前置缓冲和二次确认。
- [ ] 实现确认插话后的 TTS 停止、VoiceStudio 取消、队列清空和旧文本停止提交。
- [ ] 实现误触发后的平滑恢复，不建立虚假用户轮次。
- [ ] 对键盘、咳嗽、敲桌、风扇、音乐、扬声器回声、近讲和远讲分别测试。
- [ ] 验证安全确认提示被打断后授权失效。

## 产出

- 两阶段实时打断控制器；
- AEC/NS/AGC 音频预处理链；
- 播放参考帧与设备延迟对齐机制；
- 前置缓冲、误触发恢复和安全确认失效处理。

## 验收

- 用户正常插话时，AI 能快速降低音量并在确认后停止旧回复，用户开头语音不明显丢失。
- 单次键盘声、咳嗽、碰撞声或扬声器回声不会轻易彻底终止播报。
- 误判为疑似插话后能够平滑恢复播放，不提交虚假用户输入。
- 确认插话后旧 TTS、旧合成和旧队列均停止，下一轮继续保持人物模板。
- 安全确认被打断时不能产生授权。
- MVP-1 仍保持播放期间暂停普通录音。
