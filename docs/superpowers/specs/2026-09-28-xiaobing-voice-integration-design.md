## 边界和状态

单独的真实端口用 HTTP POST multipart `/generate`，每句显式发送 Profile ID 和 speed，不存文本/音频；限制短文本、音频大小/格式、时长、总句数、请求超时和单次请求。顺序预先合成最多三句、全部校验后再依序播放，避免合成耗时变成意外句间停顿；从第二句起在接收并校验合成音频后、提交播放前向 PCM 添加 400ms 静音。当前实例本轮仅用 Windows 默认输出设备；阻塞式子进程播放器返回只代表 API 完成；12 秒超时后强制终止子进程，但无法据此证明硬件已停止，不证明用户实际听到。提交设备后出错则保守停止，不自动重播当前句/播放后续句；中止语义没有实机证明前不纳入生产可中断播报。异步/跨线程硬中断、设备定向、Agent 出口和 P7 T-05 Edge 同句降级另行验收。

## 回退与回滚

私有配置目录固定为当前 Windows 用户的 `~/AppData/Local/ComputerVoiceAssistant`（不依赖 Codex Desktop 的沙箱化 `LOCALAPPDATA`），首次配置写入采用同目录原子落盘；同名文件存在时禁止覆盖，只有明示迁移才可更新；首次安装前不存在旧设置，回滚可删除此单独文件；不读取/改写 VoiceStudio 引擎全局默认。无效 Profile/配置、网络异常、超时、格式错误、音频设备异常全部只保留完整原文并报告不含正文/凭据的错误码；不会改变任务、授权、执行事实。停用语音时可删除本项目的私有选择文件（不修改其他文件）。本次不复写原交接中的历史测试证据，P7 不自动完成。
